# 완료 기준 검증 결과

검증일: 2026-10-27. `npm install`, `npm run build`, `npm run check:output`을 실행했습니다. Astro 7.4.2, Tailwind CSS 4.3.3, `@astrojs/sitemap` 3.7.4가 설치됐습니다. 정적 HTML 14개와 도시 상세 페이지 6개가 생성됐습니다.

| 번호 | 결과 | 확인 내용 |
| --- | --- | --- |
| 1 | 통과 | 빌드 HTML에 도시 소개, 비교표, 상품, 노선, FAQ 답변이 있습니다. |
| 2 | 통과 | CSV FAQ 질문·답변과 FAQPage JSON-LD 문자열을 비교했습니다. |
| 3 | 통과 | 6개 도시 상세 title에 각각의 도시명이 있습니다. |
| 4 | 통과 | 6개 도시 canonical이 서로 다르고 절대 URL입니다. |
| 5 | 통과 | `sitemap-0.xml`에 두 `city_slug` URL이 있습니다. |
| 6 | 통과 | 임의의 `not-a-city` 정적 URL은 생성되지 않았습니다. |
| 7 | 통과 | CSV에 없는 운영시간은 HTML에 없고, 가격이 빈 상품은 추정 가격을 표시하지 않습니다. |
| 8 | 통과 | 실제 가격 수집 성공일이 있는 상품만 확인일을 표시합니다. 30일·90일 경과 경고는 검증 스크립트에 구현되어 있습니다. |
| 9 | 통과 | 모든 예약 버튼의 `rel`과 `target`을 확인했습니다. 출처 링크에는 `sponsored`가 없습니다. |
| 10 | 통과 | 예약 버튼은 정적 HTML의 일반 `<a>` 링크입니다. |
| 11 | 통과 | 배포 HTML 전체에서 `<!--`가 0건입니다. |
| 12 | 통과 | 도시 페이지의 모든 이미지에 `width`, `height`, `alt`가 있습니다. |
| 13 | 통과 | 대표 이미지는 eager, 뒤의 상품 이미지는 lazy입니다. |
| 14 | 통과 | 도시 페이지당 H1이 1개입니다. |
| 15 | 통과 | 메인 HTML에서 6개 도시 상세 페이지로 링크가 있습니다. |
| 16 | 통과 | 도시 상세 하단의 관련 도시 링크를 확인했습니다. |
| 17 | 배포 후 확인 | 로컬 `robots.txt`와 sitemap 생성 및 HTTP 200은 확인했습니다. 네이버 서치어드바이저의 실제 읽기 성공 여부는 도메인 배포와 사이트 등록 후에만 확인할 수 있습니다. |
| 18 | 통과 | 임시 세 번째 도시와 상품을 CSV에 추가해 빌드했고, `/city/test-added-city/`가 생성됐습니다. 원본 CSV를 복구하고 다시 빌드했습니다. |
| 19 | 통과 | 각 도시 슬러그마다 정적 URL을 하나만 생성합니다. 중복 슬러그는 빌드 전 검증에서 실패합니다. |
| 20 | 원문 미완성 | 첨부된 요구사항 파일이 `20. 실제 화면`에서 끝납니다. 메인과 도시 상세 화면을 브라우저에서 직접 확인했지만, 20번의 전체 판정 조건은 파일에 없습니다. |

실제 운영 저장소의 도시 가이드와 비교 화면, 제휴 URL을 바탕으로 CSV를 교체했습니다. 6개 도시와 10개 상품의 예약 버튼이 기존 제휴 링크를 유지하는지 출력 HTML과 대조했습니다. 현재 운영 사이트의 기존 메인과 경로 확인 기능은 변경하지 않았습니다.
