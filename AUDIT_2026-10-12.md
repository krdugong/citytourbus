# CITYTOURBUS audit — 2026-10-12

Repository: krdugong/citytourbus

Reviewed affiliate links and SID tracking, deep links, SEO metadata/canonicals/sitemap, and static Vercel deployment configuration.

## High priority findings

1. Sydney Big Bus currently points directly to bigbustours.com instead of an affiliate tracking URL, so bookings can bypass attribution.

2. Chicago Big Bus uses click ID 12523133. The known current affiliate click ID is 12523142.

3. Las Vegas Big Bus uses click ID 13344537. The known current affiliate click ID is 12581783.

4. San Francisco is shown as City Sightseeing-only although a Big Bus affiliate option is available with click ID 12523200.

5. Budapest is shown as City Sightseeing-only although a Big Bus affiliate option is available with click ID 13447647.

6. SID naming is inconsistent across the site. Examples include paris, london, rome, nyc, londonEJ-code-1111 and copenhagenEJ-code-0313. A dedicated website convention such as PAR-W-citycompare, LON-W-citycompare and NYC-W-citycompare would make revenue analysis much cleaner.

## SEO findings

7. The old sitemap listed /compare?city=... URLs even though compare.html uses a fixed canonical of /compare. Those query URLs should not be submitted as unique indexable pages until they have unique server-rendered/static URLs or unique canonicals.

8. The live public host resolves as www.citytourbus.kr while HTML canonicals use citytourbus.kr. Canonical, Open Graph URL, structured data URL and sitemap should use one host consistently.

9. Home-page region counts do not match the actual data. Europe is labeled 40 but the repository contains 25 European cities. Asia is labeled 9 but the repository contains 4 Asian cities. Middle East/Africa 5 and Americas 11 are consistent, giving 45 total.

10. Several broad claims should be softened unless backed by an active official policy: 최저가 보장, 글로벌 1위, 주요 브랜드 모두 한국어 오디오 지원, 현장 구매보다 최대 20% 저렴, 공식 파트너십으로 최저가 보장.

## Deployment findings

11. This repository is a static Vercel site. There is no package.json, framework build pipeline, or GitHub Actions build workflow. Main failure risks are malformed HTML/JS, route rewrites, and stale affiliate destinations rather than package build errors.

12. No robots.txt existed on the default branch. This audit branch adds one.

13. Footer policy links on the homepage and compare page are placeholders using href="#".

## Changes already applied on this branch

- Added robots.txt
- Rebuilt sitemap.xml to contain only canonical indexable pages
- Updated sitemap lastmod to 2026-10-12
- Standardized sitemap host to https://www.citytourbus.kr
